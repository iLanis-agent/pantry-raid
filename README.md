# Pantry Raid

Dinner is already in your kitchen. Tick the ingredients you have, and Pantry Raid
ranks 20 recipes by live match score - 100% means you can cook right now, and the
rest show exactly what's missing. Vegetarian / vegan / quick (<= 20 min) filters,
short steps for every recipe.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/pantry-raid/

Pure client-side HTML/CSS/JS. No sign-up, no tracking.
